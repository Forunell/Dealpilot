# Синтетичні дані

- `example.json` — зразок старого формату v1: контакт, угода й завдання. Імпорт автоматично мігрує до v2, без вигаданих історичних дат. Прогноз UAH за весь час — 12 000 грн.
- `broken.json` — навмисно пошкоджений JSON для перевірки помилки без заміни даних.
- «Завантажити демодані» в огляді створює 12 синтетичних контактів, 20 угод і 9 завдань. Усі позначені demo: true. Дати синтетичні, відносно дня завантаження; історія починається з реальної події завантаження.

Імпорт: «Дані та налаштування» → «Імпорт JSON». Схема та зв’язки перевіряються перед підтвердженням заміни. Усі особи та компанії вигадані, email використовує example.com.
